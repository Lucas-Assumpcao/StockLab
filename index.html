SOBRE O STOCKLAB

Uma solução simples para pequenos estoques

O StockLab é um sistema fictício de controle de produtos para um comércio de bairro. Esta versão foi disponibilizada à equipe que assumirá a continuidade do projeto.

Versão1.4 (demonstração)
ArmazenamentoLocal neste navegador
PúblicoOperadores e gestores
ManutençãoNova equipe de projeto

Solicitação da empresa

A empresa deseja melhorar a confiabilidade das informações, reduzir dificuldades operacionais e planejar a próxima versão. A equipe precisa conhecer o produto antes de propor alterações.

Esta aplicação é um cenário de aprendizagem. Nenhum dado é enviado para servidores externos.
